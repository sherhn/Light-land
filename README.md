# Light — сайт

Лендинг [Light](https://github.com/sherhn/Light) — открытой модульной IDE на Rust для Windows, macOS и Linux: языковые модули, встроенный Git, терминал, локальная история и Linux через WSL.

Сайт доступен на русском и английском: <https://getlight.sherhn.space>
