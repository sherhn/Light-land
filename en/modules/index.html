SETUP

Add it in Light

  1. Open Modules in the IDE: Ctrl + Alt + P.
  2. Find a module and choose Install.
  3. Connect it to a project, or select it when creating a new one.

Modules can be installed offline from the bundled registry. Interpreters and compilers are separate tools.
